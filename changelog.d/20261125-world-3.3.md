### Simulated dungeons scale with the bots online
The number of simulated dungeon groups now follows the bots online: one group per faction for every 250 bots (500 bots = 2, 1 000 = 4, 2 000 = 8), at least one. `AiPlayerbot.CoaWorld.DungeonSim.GroupsPerFaction` now defaults to `0` (proportional) instead of `2`; a value you set yourself (1 to 10) is kept.

### Group level in the dashboard
Each dungeon or raid run in world.json (`groups.running[]` and `groups.last[]`) and each simulated run in monde.json (`dungeon_sim.last[]`) carries `level`, the group's mean level, so the dashboard can show dungeons by level band.

### Where each worn piece came from
The server records the origin of every worn piece, green or better, for players and bots: loot (and the creature, group rolls included), vendor, auction house, starting gear, or simulated dungeon. A piece whose origin the server did not see (traded, mailed, from before the update) gets no record: the armory shows it as of unknown origin. The records go to the new table `coa_item_origin` in the characters database, and the dashboard's armory shows them on each slot. On by default: `AiPlayerbot.CoaWorld.ItemOrigin.Enable = 0` turns it off. `ItemOrigin.MinQuality` (default `2`, green) sets the lowest quality recorded. `ItemOrigin.PurgeDays` (default `90`) deletes older rows; rows of deleted items always go.
